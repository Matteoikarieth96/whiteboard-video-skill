# Interview: what to ask before writing

Start from what the user already said. Ask only for what is missing, and batch the questions in one go so the user answers once.

## Must know

| Question | Why it matters |
|---|---|
| What is the topic, and what is the one thing the viewer should remember? | Every scene should serve that one idea. |
| Who is watching, and what do they already know? | Decides vocabulary, which terms need explaining, and how many numbers to show. |
| How long? | Sets the word budget: about 140 words per minute of video once pauses are counted. |
| Where will it be shown? | Talks and YouTube: 16:9. Reels, Shorts, TikTok, X mobile: 9:16. |
| Which language is the voice-over? | Picks the voice and the caption language. |

## Should know

| Question | Default if the user has no preference |
|---|---|
| Facts, numbers, documents or sources that must be used? Claims to avoid? | Research and cite primary sources. |
| Tone: playful, neutral, serious? | Friendly and plain. |
| Brand colors or a logo to draw? | The default palette: ink, blue, gold, red, green. |
| Captions on or off? | On. Most social video is watched muted. |
| Call to action at the end? | A one-line takeaway. |
| Deadline or event date? | Lets you flag facts that may change before then. |

## Good follow-ups when the brief is thin

- "If the viewer could only remember one number, which one?"
- "Is there a real example or company we should name?"
- "Anything that would embarrass you if it were wrong on screen?" Those are the facts to double-check.
